# 方案 A 设计与验收说明

## macOS 移植补充

本目录为 macOS 移植副本，原 Windows 交付未修改。新增 `build.sh`、`run.sh`，通过 Apple Command Line Tools 的 `clang++` 在目标 Mac 编译成本机程序 `bin/manual_grade`，无需 CMake 或 Homebrew；最低系统版本为 macOS 10.15。每次启动重新编译，编译成功后才替换旧程序。脚本支持中文及空格路径，检查开发工具但不自动安装。

源码补充 `<cstddef>`、`<ctime>`、`<exception>`、`<utility>` 显式标准头，减少对实现间接包含的依赖；CMake 明确设置 C++17、标准必需和语言扩展关闭。三角色权限、数据模型和业务口径未改变。目录内 evidence 为原 Windows 版本历史证据；它们不代表 Apple Clang/macOS 实机通过。当前环境没有实际 Mac 运行验证，目标机验证命令为 `sh ./run.sh --self-test`。

## 归属与设计情境

方案 A 是“模拟学生手工设计风格”的独立实现，实际由 AI 辅助生成、真实编译和执行测试。采用 C++17、文本持久化、控制台交互。没有制造真实学生手工开发时长、访谈或操作记录。

| 类型 | 职责 |

| `User` | 账号、角色、关联学号/工号、随机盐、密码散列、启用状态 |

本方案不强制继承层次；角色用字段判定，权限入口集中在 `current`、`admin`、`staff`、`classAccess`、`studentAccess`。这让学习阶段的代码控制流容易跟踪，但大量功能集中于一个类，扩展和单元替换成本高于多层架构。

## 关键算法和一致性

成绩查找及实体查询采用线性扫描。排名先筛选有效记录，再用标准排序，竞争名次通过高分列表判定。绘图使用标准 SVG 路径绘制扇形、矩形绘制柱状图，不依赖图形库。所有业务命令先保存内存副本，异常时回滚整个命令的数据变更并写失败日志；批量导入复用同一成绩授权入口。

序列化带版本和校验和；读取时先完全解析到临时 `Data`，再统一验证，成功才赋值。恢复保留当前审计记录并生成恢复前安全副本。持久化替换保留 `.previous` 以覆盖“旧文件已移动但新文件尚未重命名”的中断场景。采用教学单进程假设，无跨进程文件锁和操作系统级 fsync 持久性保证。

## 实际发现并修复的问题

1. 初次自测发现初始密码最小长度 8 与约定演示密码 `Stu@123` 长度 7 冲突。下限改为 6 字节，并统一文档。
2. 第二次自测发现使用 `std::quoted` 解析控制台参数会吞掉 Windows 路径反斜杠。改用保留普通反斜杠的命令分词器，文件序列化仍使用 `std::quoted`。
3. 排名复核发现升序显示不应把低分定义为第 1。改为升降序只改变行顺序，名次独立按高分计算，并增加回归检查。
4. 存储审查补充 `.previous` 验证恢复，避免主文件缺失时初始化新数据；备份恢复保留当前审计并生成恢复前副本。
5. 与统一报告核对时，增加缺录学生“已录科目 GPA”的明确展示；全科 GPA 与全科排名仍等待成绩齐全。
6. 图表分段标签改为半开区间，避免以整数标签造成小数成绩解释不准确。
7. 复核 Windows 启动参数后，改为读取 Unicode 命令行再转 UTF-8，避免系统 ANSI 编码影响中文 `--data` 和 `--script` 路径；通过外部 Python 子进程实测中文空格路径。
8. 排名原先已有容差，但相邻比较可能连续合并近似分数。最终改为以并列组最高分为锚，使用 `1e-9` 容差且保持原始排序的严格弱序；新增小数置换总分、均分并列及非链式分组回归检查。

以上为真实代码审查或执行测试所见的问题，不是模拟开发过程的虚构缺陷。

## 测试结果

MSVC C++17 静态 CRT 编译成功，`--self-test` 返回 0，128 项内置检查通过。独立外部验收 29 项通过。自测会在随机临时目录创建数据，成功后删除其自身临时目录，失败保留现场并返回非零；正常演示数据不参与修改性测试。

与报告核验相关的初始值：S001/S002 总分都为 240、均分都为 80、总分并列第 1；CPP 竞争名次为 1、1、3；MATH 平均 66.67、及格率 66.67%；ENG 已录 2、未录 1、均分 85；S003 已录 GPA 0.50，全科 GPA 和总均排名待齐全。

## 已知局限

只在当前 Windows x64 环境实际验证；其他平台需自行编译检查。教学规模下使用全量内存数据和整文件重写。当前角色单会话，无网络服务和多进程并发。命令输入口令可见，无本地文件加密。随机盐加迭代 SHA-256 优于明文保存，但应以成熟密码库替代后再用于实际生产。文件校验和不是认证签名；具有本地文件写权限者仍可伪造数据和审计文件。SVG 提供可打开的静态可视化，不提供交互式仪表盘。
